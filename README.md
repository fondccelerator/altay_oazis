# Инвестиционная карта Алтая · Oazis Estate

Карта: **https://fondccelerator.github.io/altay_oazis/**

## Что где лежит

| Файл | Что это | Кто правит |
|---|---|---|
| `index.html` | Сама карта: районы, застройщики, земля, юридические риски | Тимофей |
| `points.csv` | Точки с выезда и комментарии к ним | Ольга |
| `КАК-ДОБАВИТЬ-ТОЧКУ.md` | Инструкция по `points.csv` | — |

## Добавить точку

Открыть [points.csv](points.csv), нажать карандаш, дописать строку, нажать Commit changes.
Формат строки и разбор частых ошибок — в [инструкции](КАК-ДОБАВИТЬ-ТОЧКУ.md).

Битая строка карту не ломает: она пропускается, номер показывается плашкой внизу слева.

## Оставить замечание

[Issues](https://github.com/fondccelerator/altay_oazis/issues) → New issue. Текстом, можно с фото.

## Данные

Координаты объектов проставлены по центрам населённых пунктов, не по кадастру.
Маркеры разделены по достоверности: проверено по документу и требует проверки.
Источник по каждой цифре — в файле «Реестр источников» в рабочей папке проекта.
